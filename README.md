# Ohm Vision Analyzer 👁️⚡

Intelligent Breadboard Topology Extraction and Resistance Analysis System

A Computer Engineering Senior Project focused on automating the analysis of breadboard circuits. By leveraging Computer Vision and Graph Theory, this system extracts circuit topology from a single image, identifies resistors and jumper wires, and calculates the total equivalent resistance ($R_{total}$).
